# U.S. Housing Market Analysis (2000–2023)

This project analyzes long-term trends in the U.S. housing market using Python and data analysis techniques.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- SciPy

## Questions Explored

- How have home prices changed over time?
- What is the relationship between mortgage rates and housing sales?
- How has housing affordability changed?
- Which periods experienced the most market volatility?

## Skills Demonstrated

- Data cleaning
- Exploratory data analysis
- Statistical analysis
- Data visualization
- Trend analysis
